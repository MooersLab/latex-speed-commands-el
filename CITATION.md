# How to cite latex-speed-commands

If you use **latex-speed-commands** in your work, please cite it as follows.

## BibTeX

```bibtex
@software{Mooers2026LatexSpeedCommands,
  author  = {Mooers, Blaine H. M.},
  title   = {latex-speed-commands},
  version = {0.1.0},
  year    = {2026},
  url     = {https://github.com/MooersLab/latex-speed-commands-el}
}
```

## Plain text

Mooers, B. H. M. (2026). latex-speed-commands (Version 0.1.0)
[Computer software]. https://github.com/MooersLab/latex-speed-commands-el

## Note

Please update the version number and year when citing a specific
release.
